# Raya Maia — V9

Fine-tuning pass on the constellation site.

## V9 changes
- Homepage motion is now cursor-driven on fine-pointer desktop devices only; there is no autonomous drift.
- Nearby nodes are pulled a few pixels toward the cursor with a damped spring and return smoothly when the cursor leaves.
- Mobile/touch layouts remain completely still.
- Raya Maia's central label is slightly smaller to give nearby connections more breathing room.
- Academic Coaching and Contact have more visual weight in the constellation hierarchy.
- Interior scroll reveals are slower, stronger, and more gradual.
- Existing line types and colours are preserved on hover; hover changes emphasis via opacity only.

Open `index.html` to preview locally.
